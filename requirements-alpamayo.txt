# Alpamayo probe environment — MUST be a separate venv from .venv-openvla.
#
# This is not a preference. OpenVLA's trust_remote_code files target
# transformers 4.40.x (hard-pinned in requirements-openvla.txt, and a newer
# accelerate breaks its 4-bit load), while Alpamayo requires transformers
# >=4.57.1 and torch >=2.8. The two cannot share an interpreter.
#
#   python -m venv .venv-alpamayo && source .venv-alpamayo/bin/activate
#   pip install -r requirements-alpamayo.txt
#
# The upstream project installs with `uv sync` from github.com/NVlabs/alpamayo.
# Prefer that for the model package itself; these are the floors this probe
# needs on top of it.
